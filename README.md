# Поисковик этнографического корпуса

Приложение для полнотекстового поиска в корпусе этнографических интервью и текстов.

## Возможности

- 📁 **Поддержка форматов**: .doc, .docx, .txt
- 🔍 **Полнотекстовый поиск**: поиск по содержимому документов
- 📚 **Морфология**: поиск с учетом форм слов (префиксы, похожесть)
- 🌍 **Русский язык**: полная поддержка русского текста
- ⚡ **Быстрый индекс**: Whoosh FTS для быстрого поиска
- 📊 **Метаданные**: год, место, паспорт интервью
- 🖥️ **Портативность**: один exe-файл, без установки

## Системные требования

- **ОС**: Windows 7 и выше
- **Размер**: ~150-200 МБ (exe-файл)
- **Оперативная память**: 512 МБ (рекомендуется 1 ГБ для больших корпусов)

## Установка и запуск

### Вариант 1: Использование exe (рекомендуется)

1. Скачайте `ethno_corpus.exe` из папки `dist/`
2. Поместите его в папку с документами
3. Запустите exe
4. Нажмите кнопку "Анализировать"

### Вариант 2: Из исходного кода (для разработчиков)

```bash
# Установите Python 3.11+
# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python main.py

# Запустите тесты
python -m unittest discover -s ethno_corpus/tests -p "test_*.py"
```

## Структура файлов

```
ethno_corpus/
├── input/               # Входные документы (.doc, .docx, .txt)
```

## Использование

### Главное окно

1. **Дерево документов** (слева):
   - Организованы по году и месту
   - Двойной клик = открыть документ

2. **Поиск** (справа):
   - Введите запрос (например: "привет", "интервью")
   - Нажмите "Искать" или Enter
   - Результаты показывают контекст (+/- 20 слов)

3. **Кнопка "Анализировать"**:
   - Индексирует все документы из input/
   - Первый запуск: 5-10 минут (в зависимости от размера)
   - Повторный: обновляет только измененные файлы

### Примеры поиска

| Запрос | Результат |
|--------|-----------|
| `привет` | Найдет "привет", "приветствие", "привета" |
| `пришел` | Найдет "пришел", "пришла", "пришли" |
| `интервью` | Найдет "интервью", "интервьюер" |
| `место записи` | Найдет оба слова в одном контексте |

## Паспорт интервью

Каждый документ может содержать **паспорт интервью** (информацию об интервьюируемом):
- Имя и возраст информанта
- Место и дата записи
- Собеседники
- Другие метаданные

Паспорт извлекается автоматически из первого абзаца документа.

## Разработка

### Архитектура

```
PyQt6 GUI
    ↓
SearchEngine (морфология + поиск)
    ↓
IndexBuilder (Whoosh FTS)
    ↓
SQLite Database
    ↓
File System
```

### Тестирование

```bash

# Конкретный модуль
python -m unittest ethno_corpus.tests.test_morphology -v

# 33 теста должны пройти ✓
```
